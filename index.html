🚀 Đưa lên GitHub

  1. Mở Terminal tại thư mục này
  2. git init & git add . & git commit -m "mindmap"
  3. Tạo repo trên github.com → copy URL
  4. git remote add origin <URL>
  5. git push -u origin main
  6. Bật Settings → Pages → Deploy from branch
Sẵn sàng • Double-click node để sửa • Nút ⭐ để xem mẫu giống ảnh 💾 Tự lưu localStorage • Xuất PNG nền trắng giống ảnh mẫu

Cách vẽ giống ảnh mẫu

  1. Bấm ⭐ Mẫu ảnh để nạp sẵn mindmap "Phương pháp thực nghiệm khoa học".
  2. Double-click vào bất kỳ node nào để sửa chữ.
  3. Chọn node → bấm ➕ Nhánh con / ↔ Nhánh ngang hoặc phím Tab / Enter.
  4. Đổi màu nhánh ở cột trái, đổi kiểu Pill / Gạch chân cho nhánh cấp 2-3.
  5. Kéo thả node để tinh chỉnh, kéo nền để pan, lăn chuột để zoom.
  6. Bấm 🖼 Xuất PNG để ra ảnh nền trắng giống file bạn gửi.
