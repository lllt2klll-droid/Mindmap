MindMap kiểu Canva Whiteboard

  1. Double-click nền để tạo nhánh mới vào trung tâm.
  2. Chuột phải node: thêm/sửa/nhân bản/màu/kiểu/thứ tự/xóa.
  3. Kéo lên/xuống đổi thứ tự • kéo sang node khác chuyển nhánh • kéo nhẹ chỉnh tự do (có snap).
  4. Thanh quickbar bám theo node đang chọn để thao tác nhanh.
  5. Panel phải có 3 tab: Node / Chữ / Trang — bo góc, bóng, mờ, font, căn lề, nền canvas, xuất 1x/2x/3x.
  6. Topbar chuyển hướng → / ↔ / ↓ và kiểu đường cong/thẳng/góc vuông.

Phím tắt

Tab con • Enter ngang • F2 sửa • Del xóa • Ctrl+C/X/V/D • Alt+↑/↓ đổi thứ tự • Ctrl+Z/Y undo/redo • Ctrl+F tìm
